### Security

The API may be read-only, but its database credential permits writes from a reachable network host. **DEFINITELY WRONG.**
- **Upload limit applied after multipart spooling (F2).** The handler’s bounded read in [routes.py](/home/lucyc/gauntlet/AI_Invoice_Ingestion_Platform_LedgerRun/app/web/routes.py:76) occurs after multipart parsing has created the `UploadFile`; the rejection in [uploads.py](/home/lucyc/gauntlet/AI_Invoice_Ingestion_Platform_LedgerRun/app/uploads.py:63) therefore does not bound temporary disk use. **DEFINITELY WRONG.**
- **Sensitive exception text reaches logs (F3).** [jobs.py](/home/lucyc/gauntlet/AI_Invoice_Ingestion_Platform_LedgerRun/app/jobs.py:19) and [line_matching.py](/home/lucyc/gauntlet/AI_Invoice_Ingestion_Platform_LedgerRun/app/steps/line_matching.py:141) log unredacted exception details.
